# 躲在超市后门抽烟的两人

一个基于单页 HTML 制作的动漫主题静态落地页，围绕《躲在超市后门抽烟的两人》这部作品的氛围、角色与作品信息进行视觉化展示。

## 页面内容

- 主页 Hero：标题、主视觉和氛围化文案
- 双人对照区：山田与田山的左右分屏展示
- 名台词轮播：精选台词卡片
- 故事简介：作品背景与关系设定
- 角色卡片：佐佐木、山田等角色介绍
- 作品信息：连载、奖项、制作信息汇总

## 项目文件

- [`index.html`](./index.html)：GitHub Pages 入口页
- [`anime-landing.html`](./anime-landing.html)：原始页面文件
- 图片资源：`img-*.jpg` / `img-*.png`
- [`LICENSE`](./LICENSE)：自定义授权条款

## 本地预览

直接用浏览器打开 `index.html` 即可预览。

也可以用任意静态服务器，例如：

```bash
npx serve .
```

## GitHub Pages 部署

1. 将仓库推送到 GitHub。
2. 打开仓库 `Settings`。
3. 进入 `Pages`。
4. 选择 `Deploy from a branch`。
5. 分支选 `main`，目录选 `/ (root)`。
6. 保存后等待几分钟即可获得在线访问地址。
