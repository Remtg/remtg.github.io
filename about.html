关于这个站

这里记两件事：我写的东西，和站上那只猫娘。

关于我

陆晓海。浙江嘉兴。机电专业出身，现在爱折腾代码和 AI 工具。

这个博客用来记部署踩坑、工具试用、和一些没什么用但想留下来的想法。

关于猫娘

站上的猫娘来自开源项目 NekoWebShow，作者 Chocola-X。

它在浏览器里展示《猫娘乐园》的 E-mote 动态立绘 —— 可以触摸互动、播放语音、驱动口型，背景会跟着本地时间从白天变到夜晚。共 8 个角色、195 个模型。

素材来源需要说明：模型与背景图是从正版游戏解包出来的，代码是 AGPL v3 许可，素材版权归原权利人所有。这里引用它是我的个人学习与展示用途，不代表任何官方立场。

原作者的说明、部署方式和模型清单，都在 项目仓库 里。作者的部署实例在 show.nekopara.uk。

技术

本站是静态生成的，Markdown 编译成 HTML，托管在 Cloudflare Pages 上。没有数据库，没有服务器，改一行字 git push 就上线。

源码在 GitHub 仓库，构建脚本一百来行 Python，依赖只有 markdown 和 pygments。
