猫娘展示页：195 个模型的代价

2026 年 10 月 06 日

#猫娘乐园#静态资源#GitHub

想在博客侧栏放一只会动的猫娘。找了一圈，锁定 NekoWebShow —— 在网页上展示《猫娘乐园》的 E-mote 立绘，能触摸、有语音、口型同步，背景还会跟着本地时间从白天变到夜晚。

它是什么

严格说不是「后端项目」。作者在 README 里写得很清楚：

项目不需要数据库或前端构建步骤。

四个分支里三个是纯静态的。PHP 版本也只是用 PHP 读一份 JSON 来生成菜单，没有任何用户数据。

所以我上一版方案里推荐的托管数据库，纯属多余。

体积才是真问题

先看仓库：

项目 数值
仓库总体积 1.88 GB
模型数量 195
单个模型 2 ~ 3 MB
背景图 121 张
核心代码 约 150 KB

1.88 GB。GitHub Pages 免费版单站上限 1 GB —— 直接超。要么开付费版，要么换地方。

于是我选了 Cloudflare Pages。它没有这个限制，自带 CDN 和 HTTPS，构建时跑一条命令就完事。

分支怎么选

作者提供了四个分支，用途不同：

分支 形态 部署要求
main PHP 入口，含模型转换页 需 PHP + URL 重写
php_version PHP 部署版 同上
html_version 多页面静态，每模型一个 .html 静态服务即可
html_version_v2 单页面静态，#模型名 切换 静态服务即可

我选了 html_version_v2。 只有一个 index.html，切换角色在同一页面内完成，不刷新。浏览器前进后退也能切模型，选择存在 cookie 里一年有效。

关键是它不需要 URL 重写—— 这一点对托管环境的兼容性影响很大。

版权这件事得说清楚

模型和背景图是从正版游戏解包出来的素材。作者自己在 README 里承认了，来源是 UlyssesWu 的猫娘动态壁纸、NEKOPARA Vol 4 和 Afer 的解包素材，并注明「感谢正版游戏没有加密，直接就拿出来了」。

代码是 AGPL v3，允许多用、要求保留作者信息。但素材的版权和代码的许可证是两回事。

作者挂在 show.nekopara.uk 是他自己的站点，他自己承担。我要是挂在自己的域名上，那就是另一回事了。

这是我知道的，我会照实记在这里。至于是不是要长期公开，那是另一笔账，得自己算。

下一步

素材该怎么托管还没定。500MB 的模型文件直接塞 Git 仓库不太合适，单文件限制倒是不怕（每个才 2-3 MB），但仓库总体积和 clone 体验是另一回事。

几个候选：

  • Git LFS —— 存大文件的正道，但需要额外配置，且 Pages 构建时要注意拉取
  • Cloudflare R2 —— 对象存储，按量付费，但 Cloudflare 内部访问免费
  • 直接放仓库 —— 最简单，先看看实际能不能撑住

先跑起来再说。
